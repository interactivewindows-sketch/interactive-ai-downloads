# interactive ai — descargas

Página de descarga e instaladores para Windows, macOS y Linux.

Abre `index.html` para ver la página o descarga el paquete completo mediante **Code → Download ZIP**.

- [Windows](install-windows.bat)
- [macOS](install-macos.command)
- [Linux](install-linux.sh)

Nota: para ejecutar la aplicación completa también se necesitan los recursos `web/index.html` y `web/logo.jpg`, que todavía no se han añadido a este repositorio.
